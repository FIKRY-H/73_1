# WebBattery 电池监控系统

## 简介
WebBattery 是一个专业的电池监控与测试上位机软件，基于 B/S 架构设计。系统支持通过 Modbus TCP 协议与电池测试设备进行通信，提供实时数据监控、自动化测试流程控制以及数据记录功能。

## 主要功能

### 1. 数据监控
> ![主界面监控截图](assets/main_monitor.png)
> *（请将主界面截图命名为 main_monitor.png 并放入 assets 文件夹）*

- **实时数据显示**：实时展示电池电压、内阻、温度等关键指标。
- **状态监测**：监控设备运行状态、告警信息及通信状态。

### 2. 测试控制
系统提供多种测试模式，满足不同场景需求：

- **周期测试 (F1)**
  - 对选定设备进行周期性的数据采集。
  - 适用于长时间的稳定性监测。

- **静置测试**
  - 用于电池静置阶段的数据记录。

- **快速测试 (F2)**
  > ![快速测试操作截图](assets/fast_test.png)
  > *（请将快速测试操作截图命名为 fast_test.png 并放入 assets 文件夹）*

  - **功能**：高频次快速读取设备数据（30秒内读取60条有效数据）。
  - **操作**：
    1. 在设备列表中勾选需要测试的设备。
    2. 在“快速测试”按钮右侧的下拉框中选择目标设备号（1-128）。
    3. 点击“快速测试”按钮开始测试。
  - **注意**：快速测试与周期测试互锁，需先停止其他测试模式。

### 3. 设备管理
- **连接配置**：支持配置 Modbus TCP 服务器地址（IP、端口）及设备 ID。
- **多设备支持**：可同时管理和监控多个电池测试设备。

## 使用指南

### 运行程序
1. **单文件版本**：
   - 进入 `final-exe` 文件夹。
   - 双击运行 `WebBattery.exe`（或生成的单文件程序）。
   - 程序启动后会自动打开默认浏览器访问系统页面。

2. **开发环境**：
   - 确保已安装 Node.js 环境。
   - 运行根目录下的 `start.bat` 脚本可尝试自动启动。

### 界面操作
> ![设备连接配置截图](assets/connection_config.png)
> *（请将连接配置截图命名为 connection_config.png 并放入 assets 文件夹）*

- **设备连接**：在左侧或顶部菜单配置网络连接参数并连接设备。
- **数据查看**：连接成功后，主界面将显示实时数据表格。
- **导出数据**：支持将测试数据导出为 Excel 格式以便分析。

## 常见问题 (FAQ)

**Q: 浏览器没有自动打开怎么办？**
A: 请手动打开浏览器（推荐 Chrome 或 Edge），在地址栏输入 `http://localhost:8080` 访问。

**Q: 提示端口被占用？**
A: 系统默认使用 8080 端口。请检查是否有其他程序占用了该端口，或在配置文件中修改端口设置。

**Q: 快速测试无法启动？**
A: 请检查是否正在进行 F1 周期测试，两种测试模式不能同时进行。同时确保已正确选择设备号。

## 技术支持
如遇到软件运行异常或数据采集问题，请查看 `final-exe/data/logs` 下的日志文件进行排查。

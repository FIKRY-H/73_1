1.1、F1测试-充放电机操作流程

1)  下发写指令，写检测设备 0x0002 = 周期值（1\~60秒） → 启动周期测试

2)  启动检测1秒后可下发读指令，轮询读取多台设备的状态寄存器0x0000，当DATA_READY=1时，表明测试完成。

3)  当DATA_READY=1时，读取数据寄存器0x0000-0x000C，获得此次测试数据。检测设备按设定周期进行连续测试，读频率高于检测频率即可实现完整采集。

4)  下发写指令0x0002=0 结束周期测试

1.2、F2测试-充放电机操作流程

1)  下发写指令，写检测设备 0x0001 = 0x0001 → 启动快速测试

2)  启动检测1秒后可下发读指令，轮询读取多台设备的状态寄存器0x0000，当[TEST_DONE
    =1]{.mark}时，表明测试完成。

3)  当[TEST_DONE]{.mark}=1时，读取数据寄存器0x0000-0x000C，总共读取60次，获得30秒快速测试数据。此后，设备会清零状态寄存器的[TEST_DONE]{.mark}。

其中低13位\[0:12\]为电压值，单位为mV，最大值为8192mV。
上位机直接直接解析成电池电压值。
电压/阻值单位寄存器高3位\[15:13\]为阻值单位，对应如下：

  -------------------------------------------------------------------------
      \[15:13\]       0      1      2      3      4      5      6      7
  ----------------- ------ ------ ------ ------ ------ ------ ------ ------
   单位阻值（uΩ）     1      4      8      12     16     20     24     28

  -------------------------------------------------------------------------

最终阻抗值位为(阻抗寄存器值 x 阻值单位)

例如： 0x0006 寄存器值为100， \[15:13\]为5，对应的阻值单位是20
uΩ，则0x0006 寄存器对应的电池1阻抗 R3值为100x20 = 2000 uΩ。

**4 Modbus TCP 帧结构解析**

Modbus TCP 是基于以太网的 Modbus 协议封装，通信帧格式如下：

  ------------------------------------------------------------------------
     字段名       长度                         描述
  ------------- -------- -------------------------------------------------
   Transaction   2字节    主机生成的事务编号，可用于标识请求-响应对应关系
       ID                

   Protocol ID   2字节            固定为 0x0000，表示 Modbus 协议

     Length      2字节            后续所有字段（Unit ID、Function
                                       Code、数据）的总长度

     Unit ID     1字节                         0x01

  Function Code  1字节             功能码（如 0x03 读，0x06 写）

      Data       N字节                0x0000\~0x000C所有内容
  ------------------------------------------------------------------------

示例：充放电机写入 `0x000``2`` = 0x0003` 启动3秒周期测试

`00 01 00 00 00 06 01 06 00 0``2`` 00 03`

  --------------------------------------------------------
        字段名                        内容
  ------------------- ------------------------------------
    Transaction ID                   0x0001

      Protocol ID                    0x0000

        Length                       0x0006

        Unit ID                       0x01

     Function Code                    0x06

        Address                      0x0002

         Value                       0x0003
  --------------------------------------------------------

2、周期测试（F1）和 快速模（F2）读取分析

每次采样数据 = 电压 + R1 + R2 + R3 + 指数位 +状态

共占用寄存器：1+1+1+1+1+1 = 6 个寄存器（12字节）

读取策略：

充放电机一次性读取地址 0x0000 \~ 0x0005（共 6 个寄存器）

充放电机判断 DATA_READY == 1 → 完成数据同步

Modbus TCP 封包后总长度 ≈ 35 字节 ≈ 280 bit

串口透传时间：280 bit ÷ 115200bps ≈ 2.5ms

TCP延迟+MCU处理 ≈ 3.5\~4ms

单台检测设备总耗时 ≈ 6\~6.5ms

3、采用状态寄存器判断有效数据

充放电机下发写指令，检测设备收到后由于柔性调档以及其它开销，检测设备在1秒内完成设备初始化、并更新数据和状态寄存器，之后进入连续测试。

充放电机下达命令后，检测设备在1秒内完成初始化和第一次检测。之后检测设备按照设定周期循环测试。

充放电机可在检测设备完成初始化后的任意时刻读取数据。DATA_READY=1表明此次测试结束，读取寄存器
0000-000C 获取测试数据。

DATA_READY信号由检测设备控制，当一次测试结束并且数据更新后，DATA_READY置
1 。此后，当充放电机完成数据读取后，检测设备将DATA_READY清
0。只要充放电机在测试设备两次测试间完成读取，就不会丢失有效数据。

阻抗测试仪功能说明：

(1) 快速测试寄存器(0x0001)和周期测试寄存器(0x0002)不同，避免误操作。

(2) 检测设备和充放电机时钟不同，60s以上周期测试用充放电机时钟做单次测试实现。

(3) 周期测试中，检测设备只支持以1秒为步长整数周期间隔。充放电机可选择以0.1秒以上的任意步长读取检测设备寄存器数值。

(4) 快速测试中，检测设备只支持以0.5秒为步长60次连续测试。充放电机可选择以0.1秒以上的任意步长读取检测设备寄存器数值。
